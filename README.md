# Achat équipe

L'outil d'achat de l'équipe du magasin Théodore Senlis, à publier sur https://achat.nyoota.fr (v1.2 · 16/11/2026).

- Ce dépôt est public et ne contient **que du code** : aucun prix, aucun fournisseur, aucune donnée.
- Il contient l'adresse du projet Supabase et sa clé **publique** (« anon »), faite pour être publique.
  La sécurité est dans la base : sans un compte de l'équipe ouvert par Amine (liste d'accès), elle ne rend rien.
- On se connecte avec un nom et un mot de passe, créés par Amine. Aucun e-mail n'est envoyé.
- Couper un accès dans la base prend effet au prochain clic. La base note elle-même qui utilise l'outil et quand.
- `robots.txt` interdit l'indexation : l'outil n'apparaît pas dans les moteurs de recherche.

Ce dossier est fabriqué à partir de `Outil Coté equipe\Achat_equipe.html` : ne pas le modifier à la main.
